# Sports association
Simple static website for a sports association built with **HTML, CSS, and JavaScript**.  
Includes basic **Firebase integration** (Auth + Realtime Database) and local plugins (Bootstrap, jQuery, FontAwesome).

# Firebase setup
Create a Firebase project and Realtime Database in Firebase Console. Then copy your Firebase configuration and paste it into: `js/firebase_config.js`

## Run locally
Open `index.html` in your browser
